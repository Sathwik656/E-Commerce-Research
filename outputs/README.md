# Research Outputs

All artifacts in this folder are generated by:

- `python train_churn.py` — churn tables/figures (`churn_*.csv`, `churn_*.png`)
- `python train_spending.py` — spending tables/figures (`spending_*.csv`,
  `spending_*.png`), `dataset_summary.csv`, `experiment_configuration.json`,
  `customer_risk_value_examples.csv`, `model_metrics_comparison.png`

Monetary values are in **BRL (Brazilian Real)**, the currency of the Olist
dataset. Churn features/units are counts/days from Online Retail II. Raw
customer identifiers are not published in any output here.

## Metrics and tables

| File | Source model | Evaluation data | Description |
|---|---|---|---|
| `churn_evaluation_metrics.csv` | Churn (RandomForestClassifier) | Held-out test set (674 customers) | Accuracy, Precision, Recall, F1, ROC-AUC (improved 22-feature model) |
| `churn_classification_report.csv` | Churn | Held-out test set | Per-class precision/recall/F1/support |
| `churn_confusion_matrix.csv` | Churn | Held-out test set | TN/FP/FN/TP counts |
| `churn_feature_importance.csv` | Churn | Training fit | Mean decrease in impurity per feature |
| `spending_evaluation_metrics.csv` | Spending (RandomForestRegressor) | Held-out customers (621 obs) | MAE, RMSE, R2, Median AE (BRL) |
| `spending_feature_importance.csv` | Spending | Training fit | Mean decrease in impurity per feature |
| `spending_predictions.csv` | Spending | Held-out customers | Actual, predicted, residual per observation (BRL); anonymised row id |
| `customer_risk_value_examples.csv` | Prototype combination | 5 sample predictions | Risk value = churn prob x predicted spending (BRL) |
| `dataset_summary.csv` | Both | Full datasets | Row/customer counts and target statistics |
| `experiment_configuration.json` | Both | — | Model params, feature order, split info, verification |

## Notes

- The churn evaluation set is the stratified 20% hold-out from
  `customer_churn_dataset.csv`.
- The spending evaluation set contains only customers whose orders fall in the
  held-out customer split; each observation predicts spending for the
  customer's **next observed order**, conditional on a subsequent order
  existing in the dataset.
- `model_metrics_comparison.png` labels the two panels separately; churn
  classification scores and spending regression errors must not be compared
  as if they measured the same quantity.
