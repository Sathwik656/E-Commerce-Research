# Research Outputs

Two-model pipeline. All artifacts here are generated by:

- `python prepare_data.py` — builds the Olist spending datasets under `data/`
- `python train_churn.py` — churn tables/figures (`churn_*.csv`, `churn_*.png`)
  from `data/customer_churn_dataset_enriched.csv`
- `python train_spending.py` — spending tables/figures (`spending_*.csv`,
  `spending_*.png`), `dataset_summary.csv`, `experiment_configuration.json`,
  `customer_risk_value_examples.csv`

The churn model reads an enriched RFM dataset derived from **Online Retail II**
(3,370 customers, 22 features, 43% churn). The spending model reads **Olist**
prior-order history (BRL). Raw customer identifiers are not published in any
output here.

## Design at a glance

| | Churn model | Spending model |
|---|---|---|
| Source | Online Retail II (UCI 502) | Olist delivered orders |
| Population | 3,370 customers with purchase history | repeat-customer order events |
| Features | 22 enriched RFM + behavioural | prior-order history only |
| Target | no purchase in the final 90 days | payment value of the next order (conditional on it existing) |
| Split | stratified 80/20 (2,696 / 674) | out-of-time: orders before vs after 2018-01-01 |

## Notes

- Churn is evaluated on a stratified 20% held-out test set (674 customers,
  43% churn) that was never used for fitting; the 5-fold CV ROC-AUC on the
  training split is the more reliable generalisation estimate.
- The churn target is **near-balanced (~43%)**, so no oversampling, undersampling
  or class weighting is applied. The model reaches Accuracy 0.659 / ROC-AUC 0.715
  on the test set, beating the 0.570 majority-class baseline.
- The churn model reads an Online Retail II-derived dataset; the spending model
  reads Olist. The two models are trained on **different populations**, so the
  combined Customer Risk Value is a demonstration, not a per-customer truth.
- The spending evaluation set contains only orders placed after the split date;
  each observation predicts the spending of the customer's next order,
  **conditional on a subsequent order existing**.
- Churn classification scores and spending regression errors are different
  quantities and must not be compared as if they measured the same thing.
